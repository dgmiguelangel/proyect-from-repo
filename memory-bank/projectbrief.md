# Sistema de Control de Stock

Aplicación web para administrar el inventario de un pequeño comercio.

## Funcionalidades
- Registrar productos.
- Modificar y eliminar productos.
- Consultar existencias.
- Registrar entradas y salidas.
- Detectar productos con stock bajo.

## Reglas principales
- Un único administrador.
- No permitir stock negativo.
- No incluir facturación.
- Registrar los movimientos de stock.
